# AxonTube v0.5.3 — Public preview / 公开预览版

[English](#english) · [简体中文](#简体中文)

## English

The first public application preview brings AxonTube 0.5.3 to **Apple Silicon
Macs (arm64)**. Learn from videos with two subtitle tracks, sentence practice,
and material you can save for later. This release retains the 0.5.3 application
interface.

### Downloads

- [AxonTube-0.5.3-macos-arm64.dmg](https://github.com/axonvoss-labs/AxonTube/releases/download/v0.5.3/AxonTube-0.5.3-macos-arm64.dmg)
- [AxonTube-0.5.3-macos-arm64.zip](https://github.com/axonvoss-labs/AxonTube/releases/download/v0.5.3/AxonTube-0.5.3-macos-arm64.zip)

Use the DMG to drag the app into Applications, or extract the ZIP.
See the [installation guide](../INSTALL.md) for checksum verification and
first-launch instructions.

### What you can do

- Read two independent subtitle tracks, defaulting to English and Traditional
  Chinese. Select from the current video's available original captions and
  YouTube automatic translations.
- Search sentences, jump to a sentence, replay or loop it, change playback
  speed, and adjust subtitle text size and each track's timing.
- Save accessible video into a new folder. Available captions add timed SRT
  tracks and bilingual reading files; video-only saving is supported. Saving
  remains available while captions load, and unfinished work stays in a
  `.partial` folder.
- Export loaded subtitles as Word, TXT or SRT. A single loaded track can still
  be exported; Word and TXT pair bilingual text by overlapping times.
- Choose among 24 interface languages, including Arabic and Hebrew RTL
  layouts. Local videos and saved subtitles work offline. No paid AI API key
  is required; YouTube supplies website captions and automatic translations.

The 24-language count describes interface choices. Subtitle availability
depends on the video and is not a guarantee of learning fluency.

### Compatibility and known limits

- **System:** macOS 14 or later is the deployment target. Only Apple Silicon
  on macOS 26.5.2 has been tested; other versions, including macOS 27, and
  Intel Macs remain unverified.
- **Signing:** this is an ad-hoc-signed preview, without Developer ID signing
  or Apple notarization. Follow the per-app first-launch steps in the
  [installation guide](../INSTALL.md).
- **YouTube:** the latest live download check encountered sign-in / bot
  verification. Successful current online caption and video downloads have
  not been established. Some videos prohibit embedding or require an account;
  in-app Google SSO is not implemented, and browser playback has a separate
  login and playback session.
- **Formats:** saving uses a complete audio/video stream and does not merge
  separate high-resolution streams. Local playback depends on codec support.
  Optional FFmpeg conversion may omit extra audio tracks, HDR or embedded
  subtitles. ASS/SSA import preserves text only; automatic captions,
  translations and timing-based bilingual pairing can contain errors.
- **Study history:** playback-history restoration, vocabulary collections,
  spaced review, OCR and image-subtitle extraction are not implemented.
  Remembered language preferences are not saved learning progress.

### Verification and dependencies

The recorded 0.5.3 application checks passed: **105 core checks, 138 model
assertions, 29 caption checks, 60 video-save checks and 317 native-interface
assertions**. All 24 interface languages were selected in the app; six
interface languages and compact German layouts were reviewed.

These are recorded application results. Offline caption fixtures and
fake-helper save tests do **not** prove live YouTube availability or wider Mac
compatibility. See the [verification record](../VERIFICATION.md) for the scope
and evidence; translation switching checks are not professional native-speaker
review of every translation.

The app includes its own pinned Python runtime, YouTube helper and JavaScript
runtime. It does not require system Python, a separate dependency installer or
first-launch downloads of these components. The companion dependency-materials
archive is for source and license inspection; it is not needed to run the app.

The application uses the [MIT License](../../LICENSE). Third-party components
retain their own terms; bundled-helper and source details are documented in
[dependency and source information](../SOURCE-ACCESS.md) and
[third-party notices](../../NOTICE.md). AxonTube is not affiliated with
YouTube, Google or Apple.

### 可用功能

- 阅读两条独立字幕轨道，默认英语和繁体中文；可从当前视频提供的原始字幕及
  YouTube 自动翻译中选择。
- 搜索句子、点击跳转、重复或循环播放，调整播放速度、字幕字号和各轨道的时间偏移。
- 将可访问的视频保存到新文件夹；有可用字幕时添加带时间轴的 SRT 和双语阅读文件，
  也支持仅保存视频。字幕加载期间仍可保存；未完成的内容保留在 `.partial` 文件夹中。
- 将已加载的字幕导出为 Word、TXT 或 SRT。只有一条字幕轨道时也能导出；
  Word 和 TXT 按时间重叠关系配对双语内容。
- 选择 24 种界面语言，包括阿拉伯语和希伯来语的从右到左布局。
  本地视频和已保存字幕可离线使用，无需付费 AI API 密钥；网站字幕和自动翻译由 YouTube 提供。

24 种语言指界面语言选项。字幕是否可用取决于视频，也不代表对语言熟练程度作出保证。

### 兼容性与已知限制

- **系统：**部署目标为 macOS 14 或更高版本。目前仅测试了运行 macOS 26.5.2 的
  Apple Silicon Mac；包括 macOS 27 在内的其他系统版本和 Intel Mac 尚未验证。
- **签名：**此预览版采用 ad-hoc 签名，没有 Developer ID 签名，也未经过 Apple 公证。
  请按[安装指南](../INSTALL.md)中的单个应用例外流程完成首次启动。
- **YouTube：**最近一次在线下载检查遇到登录／机器人验证，尚未确认当前在线字幕及
  视频下载能够成功。部分视频禁止嵌入播放或要求登录账户；应用内未实现 Google SSO，
  浏览器播放使用独立的登录状态和播放会话。
- **格式：**保存使用完整的音视频流，不合并分开的高分辨率流。本地播放取决于编解码器
  支持；可选 FFmpeg 转换可能丢失额外音轨、HDR 或内嵌字幕。ASS/SSA 仅导入文本；
  自动字幕、翻译和按时间配对的双语内容可能有误。
- **学习记录：**尚未实现播放历史恢复、词汇收藏、间隔复习、OCR 或图片字幕提取。
  保存语言偏好不等于保存学习进度。
