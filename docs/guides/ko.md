YouTube를 나만의 어학 교실로 바꿔 보세요. YouTube 자막과 자동 번역으로 좋아하는 동영상에서 배우세요. 두 언어를 나란히 읽고, 각 문장을 반복 재생하고, 중요한 학습 자료를 간직할 수 있습니다.

**24개 인터페이스 언어 · 다국어 자막**

24는 인터페이스에서 선택할 수 있는 언어 수입니다. 자막 언어는 선택한 동영상에서 제공하는 트랙에 따라 달라지며, 24개 언어를 유창하게 구사하게 된다는 보장은 아닙니다.

## 시작하기

### 1. YouTube 열기

동영상 링크를 붙여 넣으세요. 사용 가능한 자막을 자동으로 요청하며, 기본값은 첫 번째 영어, 두 번째 중국어 번체입니다. 처음 가져올 때는 약 1~2분이 걸릴 수 있으며, 자막 제공 여부는 보장되지 않습니다.

### 2. 선택하고 연습하기

화면에 있는 두 자막 드롭다운을 사용하세요. 문장을 클릭해 해당 위치로 이동하거나, 다시 재생하거나, 문장 반복을 켤 수 있습니다.

### 3. 저장 또는 내보내기

'동영상 저장'에서는 접근 가능한 미디어와 제공되는 자막을 저장할 폴더를 선택합니다. '이중 언어 자막 내보내기'는 불러온 자막으로 Word, TXT 또는 SRT를 만듭니다.

### 4. 나에게 맞추기

인터페이스 언어, 재생 속도, 자막 크기, 각 트랙의 시간 보정값을 바꿀 수 있습니다. 앱은 인터페이스와 자막의 언어 선택을 기억합니다.

## 사용 가능한 기능

### 독립적인 두 자막 트랙

기본값은 영어 / 중국어 번체입니다. 현재 동영상에서 제공하는 원본 자막과 자동 번역 중에서 선택하세요. 두 번째 트랙을 가져오지 못해도 성공적으로 불러온 첫 번째 자막은 계속 사용할 수 있습니다.

### 문장에 집중하는 연습

문장 검색, 클릭으로 재생 위치 이동, 이전 / 다음 문장, 다시 재생, 반복, 재생 속도 조절, 현재 문장 따라가기를 지원합니다.

### 동기화된 자막과 동영상 저장

자막을 불러오는 중에도 저장할 수 있습니다. 저장할 때마다 접근 가능한 동영상을 위한 새 폴더를 만들고, 자막이 있으면 시간 정보가 포함된 SRT 트랙과 이중 언어 읽기 파일도 담습니다. 자막 없이 동영상만 저장할 수도 있습니다. 완료되지 않은 작업은 .partial 폴더에 남습니다.

### Word, TXT, SRT 내보내기

시간 보정값을 적용해 사용 가능한 자막을 내보냅니다. Word와 TXT는 시간이 겹치는 구간을 기준으로 두 언어를 짝짓습니다. 한 트랙만 불러온 경우에도 해당 내용을 내보낼 수 있습니다.

### 24개 언어로 제공되는 인터페이스

메뉴, 상태 메시지, 학습 슬로건의 언어가 함께 바뀝니다. 아랍어와 히브리어는 오른쪽에서 왼쪽으로 읽는 레이아웃을 지원합니다. 인터페이스 언어를 바꿔도 자막 내용은 바뀌지 않습니다.

### 로컬 재생과 명확한 조작 상태

파일 메뉴에서 로컬 미디어와 자막 파일을 엽니다. 사용할 수 없는 동작은 이유와 함께 흐리게 표시하고, 선택한 모드는 강조 표시와 체크 표시로 나타냅니다. 저장 중에는 작업 중 상태를 보여 줍니다.

## 학습에 도움이 되는 점

### 시청에서 연습까지 간단한 흐름

도구 모음의 네 가지 동작으로 주요 작업을 바로 진행합니다: YouTube → 동영상 저장 → 자막 → 언어. 자막을 가져오는 별도 버튼은 필요하지 않습니다.

### 간직할 수 있는 학습 자료

시간 정보가 포함된 자막과 읽기 편한 Word / TXT 파일은 듣기 연습과 나중에 복습할 때 모두 유용합니다. 새 위치에 내보내므로 원본 파일은 유지됩니다.

### 로컬에서 사용, AI API 키 불필요

로컬 미디어와 저장된 자막은 오프라인에서 사용할 수 있습니다. 웹사이트 자막과 자동 번역은 YouTube가 제공합니다. 앱은 원격 측정 정보를 수집하거나 로컬 미디어를 업로드하지 않으며, 유료 AI API 키도 요구하지 않습니다.

## 미해결 문제와 제한 사항

### P0 · YouTube 자막과 동영상의 이용 가능 여부

**실제 서비스 검증**

최근 실제 서비스 확인에서는 YouTube의 로그인 / 봇 확인 요구에 막혔습니다. 현재 온라인 다운로드가 성공하는지는 확인되지 않았습니다. 공개 배포 전에 사용하려는 네트워크와 대표적인 여러 동영상에서 검증해야 합니다.

### P1 · 임베드 및 계정 제한이 있는 동영상

**플랫폼 제한**

일부 제작자나 동영상은 임베드 재생을 허용하지 않습니다. 앱 내 Google SSO는 구현되지 않았습니다. 브라우저 바로가기는 별도의 로그인 및 재생 세션을 사용합니다. 이러한 제한이 해결되었다고 안내할 수 없습니다.

### P1 · 서명과 더 폭넓은 Mac 테스트

**배포와 호환성**

패키지는 ad-hoc 서명되었으며 Developer ID 공증은 없습니다. macOS 26.5.2의 Apple Silicon에서 테스트했으며, macOS 27과 Intel Mac은 테스트하지 않았습니다. macOS 14는 배포 대상 버전일 뿐, 모든 버전을 테스트했다는 근거가 아닙니다.

### P2 · 다운로드 품질과 자막 충실도

**형식과 품질 제한**

저장에는 오디오와 비디오가 모두 포함된 스트림을 사용하며, 분리된 고해상도 스트림을 병합하지 않습니다. ASS/SSA에서는 텍스트만 가져옵니다. 자동 자막, 번역, 시간 기준의 이중 언어 짝짓기에는 오류가 있을 수 있습니다. 로컬 재생은 코덱 지원 여부에 따라 달라집니다. 선택 기능인 FFmpeg 변환에서는 추가 오디오 트랙, HDR, 내장 자막이 누락될 수 있습니다.

### P2 · 학습 기록과 학습 도구

**미구현**

재생 기록 복원, 단어장, 간격 반복 복습, OCR, 이미지 자막 추출은 구현되지 않았습니다. 언어 설정 저장은 학습 진행 상황 저장을 의미하지 않습니다.

### P2 · 원어민 언어 검토

**문안 검토**

24개 인터페이스 언어와 번역된 슬로건은 모두 전환 검사를 통과했습니다. 이는 지원 범위와 동작을 확인한 것이며, 모든 번역이 전문 원어민 검토를 받았다는 뜻은 아닙니다.

## 검증된 내용

0.5.3에서 코어 검사 105개, 모델 단언 138개, 자막 검사 29개, 동영상 저장 검사 60개, 네이티브 인터페이스 단언 317개를 통과했습니다. 실제 메뉴에서 24개 언어를 모두 선택했으며, 6개 인터페이스 언어와 좁은 화면의 독일어 레이아웃을 검토했습니다.

로컬 재생, 내보내기, 상태 전환, 네이티브 저장 대화상자를 검증했습니다. 오프라인 테스트 데이터와 모의 도우미를 사용한 저장 테스트만으로는 YouTube가 현재 온라인 자막 또는 동영상 다운로드를 허용한다는 사실을 입증할 수 없습니다. 사용자 인증 정보는 가져오지 않았습니다.
